A compact implementation of Maskaglia

Exact-integer runtime sampling, 32-lane bitslicing, one to four Boolean shares, fixed public batching, and a share-aware two-center adapter for post-quantum schemes.

Security boundary: the source follows the paper’s probing-model gadget structure. Compiler preservation and physical leakage have not been established, so this is research software—not a generic side-channel-security claim.

Implemented software path

  • Integer scalar referenceNo runtime floating point; exact saturated geometry and generated boundary counts.
  • Portable masked core32 candidates per word, 1–4 Boolean shares, CS20-style secure AND, masked compare, equality, Bernoulli, and fused Laplace evaluation.
  • Fixed scheduler128 candidates per output block, fixed-address accepted-lane selection, complete output zeroization on the bounded failure path.
  • Caller-owned randomnessExact-fill callbacks and distinct streams for sampling coins and fresh masking randomness.
  • Share-aware adapterSamples both centers, masked-selects with the center bit, and returns shared x = 2y − t.
  • Compact evidence suiteVectors, gadget truth tables, distribution moments, MPFR table checks, sanitizer/fuzz/Valgrind, CBMC, and cross-compilation.

Correctness before cleverness

The implementation does not copy the supplement’s aggressive K = 40 cut: that check considers aggregate acceptance but makes some output tails unreachable. It uses the exact saturation Ksat = max(qy) + 1 instead. The equality boundary accepts on the strict test U < floor(2pTy). 

profile + coins ── fused 32-lane candidates ── masked accept bits
       separate mask RNG ── SecAnd / refresh ── public schedule
       shared samples ── consumer adapter ── shared representation

Public tables are scanned and masked-selected; candidate values never become memory indices. The library core allocates no heap and contains no scheme-specific key or signing logic.

Claims stop where measurements stop

Passing functional, sanitizer, compiler, and proof checks establishes a useful software baseline. It does not establish physical resistance. AVX2 speedups, board cycles, compiler-induced leakage, and power/EM results are deliberately absent until measured on named targets.

The HAWK-shaped adapter is functional and keeps samples shared, but the bundled research widths are not HAWK v1.1’s official widths. A complete masked signer would additionally need a justified Boolean-to-arithmetic conversion and protected downstream arithmetic.
